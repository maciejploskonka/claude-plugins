# claude-plugins

Claude Code plugins by Maciej Ploskonka.

| Plugin | What it does |
| --- | --- |
| [pulse](plugins/pulse) | A live bar above the prompt (context, cache, limits, cost) and a handoff flow, set up once with a short wizard. |

## Install

In a Claude Code terminal session:

```
/plugin marketplace add maciejploskonka/claude-plugins
/plugin install pulse@maciejploskonka
```

Answer `y` to add the marketplace, then pick a scope (`user` for every project).
